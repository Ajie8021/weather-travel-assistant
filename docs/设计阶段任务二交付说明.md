# 设计阶段交付说明（UML、业务规则与后台原型）

## 1. 交付概述
本阶段完成了智能助手系统的架构图表设计、核心业务规则定义、字段需求说明以及后台管理原型的搭建。所有图表均保留了可编辑源文件（.drawio），业务规则严格对标现有代码实现，原型提供了真实的可交互链接与全状态截图。

## 2. 交付物清单

### 2.1 UML 设计图表（位于 `docs/design/`）
| 文件名                                      | 说明                                                         |
| ------------------------------------------- | ------------------------------------------------------------ |
| `use-case.drawio` / `.png`                  | 系统用例图。覆盖 4 类参与者（普通用户、管理员、ESP32-S3 设备、第三方服务）与 7 项核心用例。 |
| `plan-generate-activity.drawio` / `.png`    | “生成一日行程”活动图。包含正常流程及天气数据缺失、景点为空等异常分支。 |
| `conflict-confirm-activity.drawio` / `.png` | “天气冲突确认”活动图。包含检测、用户确认/取消、修改及重新检测的完整闭环。 |
| `plan-modify-collaboration.drawio` / `.png` | “局部修改行程”协作图。展示了各层对象（Controller、Service 等）间的消息传递与职责。 |

### 2.2 业务与字段文档（位于 `docs/design/`）
| 文件名              | 说明                                                         |
| ------------------- | ------------------------------------------------------------ |
| `business-rules.md` | 核心业务规则说明。明确了高温/低温/大风/降雨/雷暴阈值（与代码对齐）、`needConfirm` 触发条件、未确认不改、仅改目标时段及数据缺失处理策略。 |
| `field-spec.md`     | 提供给成员一的数据库字段建议。涵盖行程、日程项、冲突记录、修改记录等 DTO 与实体映射建议。 |

### 2.3 后台管理原型（位于 `docs/prototype/`）
| 文件名/目录                  | 说明                                                         |
| ---------------------------- | ------------------------------------------------------------ |
| `admin-prototype-link.md`    | **原型公开预览链接**及所有页面的截图索引。                   |
| `admin-ui-design/`           | 6 个后台页面的真实截图（包含正常态、空态、失败态）。         |
| `admin-interaction-rules.md` | 后台各页面的路由、字段、查询/重置/详情交互及异常提示的规则说明。 |

## 3. 验收点自检对照

- [x] **用例图覆盖**：包含查天气、查景点、规划路线、生成计划、修改计划、语音交互、后台管理共 7 项。
- [x] **活动图分支**：生成计划与冲突确认图均包含异常处理与取消分支。
- [x] **规则阈值一致**：五类天气阈值与 `WeatherConflictProperties.java` 及 B 模块交付文档完全一致。
